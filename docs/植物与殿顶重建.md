# 植物、殿顶与院墙重建（2026-11-05）

## 调研结论及证据边界

用户截图体现的是有顶殿堂向庭院望出的空间，而非露天蒲团广场。不能只靠截图判断 SANSA 使用哪个树木生成器，也不能把其打包代码中 Three.js 的通用 alphaTest 定义当成具体植物实现的证据。

本次采用的技术参考：

- Three.js 官方材质文档：https://threejs.org/docs/pages/Material.html ，叶片透明轮廓采用 alphaTest，保持深度写入；alphaToCoverage 在启用多重采样时平滑边缘。
- EZ-Tree：https://github.com/dgreenheck/ez-tree ，MIT，Daniel Greenheck。采用 npm 1.1.0 的树干分叉与叶片几何生成算法。GitHub 当前主线含更多新功能，不能将其 LOD 能力误称为此版本已接入的能力。
- 北京文旅官方参考：https://www.visitbeijing.com.cn/article/4A5vjINzRuI 、https://www.visitbeijing.com.cn/article/47QkhlrYGoi ，参考雍和宫秋季银杏、朱墙、黄瓦的色彩关系，不复制建筑实测尺寸。
- 南京地方志建筑资料：https://dfz.nanjing.gov.cn/ztzl/njzj/szcs/200806/P020210517585259435810.pdf 。仅作中国寺院回廊、青石铺地与檐下空间方向参考，不声称桂花树为鸡鸣寺某株实景复刻。

## 落地

1. 去除压扁球体叶片、球形背景林与锥形树林。用分叉树干、透明叶簇、自绘叶脉、冠层法线构成植物。
2. 银杏与桂花分别配置冠幅、分枝角度、树皮、叶形、颜色；远景降低分枝与叶片数量，近景保留细节。这是分档生成，不是动态 LOD。
3. 采用原创建筑表面纹理：朱墙微颗粒、低强度木纹、屋瓦接缝。屋面增加 UV、筒瓦线、檐下椽木；回廊移除实心封板，保留四周承重梁。
4. 前庭撤除蒲团及露天佛像，改为殿门、格窗和台阶；“入殿礼拜”进入有顶主殿，随后选蒲团。室内保留藻井，并增加入口檐下椽木、宽门洞、柱梁、门外树景与地灯。
5. 院墙改灰砖墙脚、朱墙、灰瓦压顶，减少金色圆球装饰。

## 源码与许可

app/vendor/ez-tree 为 npm 1.1.0 源码副本：保留 tree、rng、branch、enums、options、trellis；不引入默认预设与自动加载纹理，textures.js 改为空贴图接口，实际材质在 app/plants.js 中由本项目提供。保留 LICENSE，并在 public/models/ez-tree-LICENSE.txt 提供许可。其余叶片画布、物种配置、建筑材质与布局为本项目创作。未使用 SANSA 的模型、纹理或音频。

这是面向浏览器的艺术化重建，并非真实寺院扫描模型；仍不能以程序化植物替代完整实景测绘质量。


## 追加：两张近景截图对应的材质与水景改造

核查 SANSA 官方公开前端包发现实际资源引用（不是只检索到 Three.js 内置定义）：`/assets/materials/{ground,plaster,rock,roof,stone,wood}/{color,normal,roughness}.jpg`、`/assets/environment/woodland.jpg`、`/assets/models/pine.glb`、`/assets/models/buddha.glb`。这些证据支持其使用配套表面材质与 GLB 资产；不据此推断所有树木均为 GLB 或某一商业生成器。仅记录路径，未下载复制这些资产到本项目。

本项目改造：
- 地表采用 Poly Haven 的 Forest Ground 01 与 Rock Tile Floor（CC0）。保留来源 JSON，1K 材质转换为 WebP。颜色图为 sRGB，法线与粗糙度为线性数据。
- 原满铺广场改为轴线石板路、横向步道与落叶土壤，植物基部不再立在纯色板上。
- 荷池移至院内西侧，采用不规则轮廓、石岸、荷叶、水草；步行网格排除池面，点击水面走近岸边并切换赏荷视角。
- 水面采用 Three.js 0.187 的 Water 示例组件，256px 反射缓冲、每三次渲染更新反射，使用本项目生成的周期法线。复制到 vendor 的唯一生命周期改动为暴露 renderTarget 销毁接口，保留 THREE-LICENSE。不是单纯蓝绿色贴片，也不声称是 SANSA 相同水体实现。
- 模型升级为高一些的柱廊、门洞内可见造像；真实礼拜仍进入有顶殿堂。入口檐下增加椽木，宽门洞可看见院外树景与灯。

材质来源：https://polyhaven.com/a/forrest_ground_01 、https://polyhaven.com/a/rock_tile_floor ；许可：https://polyhaven.com/license 。水面技术：https://threejs.org/docs/pages/Water.html 。
