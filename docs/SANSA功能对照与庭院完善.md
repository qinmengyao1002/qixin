# SANSA 功能对照与庭院完善

2026-11-05。本表区分公开代码线索和本项目实现，不代表已人工试玩 SANSA 全部隐藏或地区限定功能。

## 参考来源和设计边界

- 官方入口：https://sansatemple.com/ 。主页明确提供念珠、礼拜和短暂休息空间。
- 官方当前公开前端包：通过 scripts/audit-sansa.mjs 读取，检查本地 ../docs/sansa-current-public.js。用于核对交互文案与状态，不复制其代码、模型、纹理或音频。
- 中国建筑方向沿用殿内重建设计文档的雍和宫实景来源；庭院采用朱墙、灰瓦回廊、山门、荷池、茶亭等中国寺院常见构成，是原创组合，不称为真实雍和宫或鸡鸣寺测绘复刻。

## 本轮落地

- 三处室外区域共享完整四面庭院背景；灰瓦回廊、山门、荷塘、茶桌、地灯与外围树景。
- 相机增加室内外各自边界和缩放上限，初始镜头缩短以避开山门牌匾，右键旋转而非无限平移。
- 北京时间默认自动模式，5:30–7:30 渐亮，17:00–19:30 渐暗；手动预览午后、落日、月夜随时可回自动。
- 新增茶桌可点击目标、寻路抵达、杯子显示和短暂休憩；移动可中止。

## 尚需继续的质量工作

院落目前仍通过已有地图/门户切换，尚不是多殿无缝连续开放世界。听荷亭和荷塘尚未接入可行走区域。外观仍有程序化几何，植物、材质和人物动作尚未达到用户参考的完整美术质量。不能将本轮称为全部功能补齐或最终美术验收。
