# 茶咖与河灯：本地更新

本文件更新上一版《SANSA功能对照与庭院完善》中的茶馆、座椅和荷池状态。

- 桂隐茶咖：完整瓦顶亭屋、柜台、咖啡机、茶罐、菜单。提供桂花乌龙奶茶、松风拿铁、桂花清茶、青梅冷萃，均为免费虚拟饮品。
- 点单后自动走到柜台，备茶三秒，取杯后可走动或坐下。三次饮用后收杯，也可提前取消。
- 六个座位：茶桌双座、东廊双座、听荷池畔、西廊晚照。自动寻路、坐下、起身；服务器独占，断线超时释放。
- 莲灯：四句祝愿，独放即时入水；共同放灯准备20秒，按服务器时间同时入水。同房间共享灯盏与确定性轨迹，不同房间隔离。
- 灯在池面漂流约三分钟后淡出；每位访客十秒限一次，每池最多48盏。纯虚拟心愿体验。
- 美术：银杏扇叶、桂花树枝叶、CC0石径和落叶土地材质、荷池反射和涟漪、岸石、芦苇、莲叶、完整殿顶梁架。原创庭院组合，并非真实寺院测绘复刻。
