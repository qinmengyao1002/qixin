# 殿内重建：雍和宫视觉依据

## 依据与边界

本轮以雍和宫的真实照片为主要依据，没有把韩国寺院的背景搬进来，也没有把鸡鸣寺与藏传佛教殿堂的陈设混称为同一建筑。

- 北京市民族宗教事务委员会的雍和宫介绍：https://mzzjw.beijing.gov.cn/bjmz/201912/t20191215_1235552.html
- 雍和宫殿介绍（中国网）：https://www.yonghegong.cn/node_7249369.htm 。搜索可读，正文访问返回 403，未声称完整读取。
- 故宫博物院资料《浓厚汉藏混和风的法轮殿》：https://www.dpm.org.cn/Uploads/File/pdf/0a/99/be/0a99bebb5b1b9a1a2b1c127c1f1364ab.pdf
- 殿内实景照片核对：https://www.businessinsider.jp/article/271171/ 与 https://www.tripchinaguide.com/photo-p847-12083-the-buddha-statues-in-beijing-yonghe-temple.html 。照片仅用于观察结构，未作为游戏纹理或再发布的图像。

照片中可直接观察的要素：朱红柱墙、青绿彩绘格状天花、鎏金雕花背光、红蓝色嵌饰、深蓝发髻与金色面部、悬挂织物、层叠供桌及密集供器。这些是本次设计的对应依据。游戏没有精确复刻真实佛像的手印、衣着和各殿全部陈设。

## 实现

- 新建 app/temple-interior.js，独立维护殿内构件；world.js 调用并按新增柱网重建行走障碍。
- 三块简化绿板替换为雕花材质背龛，外侧有立体厚框、串珠边饰；细部采用贴图及微小凹凸，不宣称所有雕花都已逐一建模。
- 增加彩绘天花、梁枋、叠涩柱头构件、窗框和下部菱花纹、石柱础。
- 佛坛、莲座与供桌分层；增加车旋烛台、烛身火焰、七只供水碗、花瓶与莲花、垂挂织物。
- 坐佛继续使用上一轮已核验 CC BY 的扫描造型，使用独立顶点着色补充金面与深蓝发髻；这是游戏配色适配，并非取得雍和宫文物扫描。
- 建筑静态网格按材质合并；雕塑、交互目标和灯光独立；增加窗侧阴影。
