# 游园地图与取香台（2026-11-06）

地图最终按用户要求改为游戏式空间地图，不沿用表格式活动卡片。
- SVG 绘制殿堂中轴、院墙、门廊小路、池塘、茶馆、座位、银杏树及院外乐庭。
- 十二个可访问的图标入口；活动名称默认收起，悬停/聚焦显示完整名称和玩法，点击进入对应院落或活动面板。
- 触屏点图标显示说明，再点“前往这里”。键盘 Tab 聚焦显示同一提示，Enter 可进入。

敬香：炉旁木桌、香盘、备用香；先寻路至取香台，伸手拿香，双手持香走到香炉前，再举香礼敬与缓慢下插，最后显示插好的香和烟。取香 3.4 秒，炉前动作 9.2 秒（不计走路）。同一束香保持相同尺寸，插香和取香两个阶段分开，避免状态覆盖跳过取香。点击地面可中断。
