# 室外点击行走修复

## 复现与根因

银杏前庭点击中央石板路却弹出茶咖菜单。记录射线命中结果：kind=cafe、geometry=SphereGeometry，命中坐标和距离均为 NaN（JSON 序列化显示 null）。

茶馆 started 初值为负无穷；未开始制作时蒸汽动画仍计算余数，生成 NaN 坐标。Three.js Raycaster 仍会检测不可见模型，隐藏蒸汽的异常命中抢走地面点击。这也解释了室内较正常、共用茶馆的室外场景异常。

## 修改

- 茶饮未开始制作时不更新蒸汽动画，所有模型保留有限坐标。
- 点击检测排除非有限命中、不可见对象及不可见祖先。
- 不选择地平面之后的交互物；射线没有碰到地面时不发出走路指令。
- 保留原有相机跟随、互动、寻路和碰撞规则。

## 验证

- 浏览器原位置修复前打开茶菜单，修复后正常沿道路移动。
- 月下乐庭点地移动；结缘小院点蒲团移动礼拜，再点空地起身行走。
- 礼佛殿中央过道点地移动并恢复跟随。
- node scripts/check-interaction-picking.mjs：复现真实 Three.js NaN 命中，检查隐藏父级、有效物体和地面深度过滤，通过。
- npm run check、npm run build 通过；构建仍有原有的大包体积提示。
