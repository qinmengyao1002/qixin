# 雍和小院

雍和宫灵感的中文 3D 慢生活小院。原创圆润角色、猫狗、金瓦红墙与银杏；非雍和宫官方产品。

## 体验

- 七处院落，点地寻路、蒲团礼拜、合掌、各殿供奉介绍。
- 108 念珠、电子木鱼、点香、原创环境声景、昼夜与拍照。
- 三款手串，服务器计时等候、捧串跪候、离开后提醒、纪念册。
- 猫狗抚摸、跟随、打盹、围着玩家跳舞；乐庭舞蹈和同房邀请。
- 三个房间，真人状态同步、座位互斥、同房链接。场景 NPC 明确标注为小院住客。
- 手机触控、键盘操作、减弱动效与低画质。纪念存本机，刷新保留当前会话和手串票据。

## 运行

Node 22.13+；安装 `npm ci`，启动 `npm run dev -- --port 5198 --hostname 127.0.0.1`。数据库初次使用需应用 `drizzle/` 下的迁移到 Wrangler 本地 D1。类型检查 `npm run check`，构建 `npm run build`。开发服务运行时执行 `npm run test:api` 验证房间隔离、身份、抢座、邀请和完整手串计时流程。

## 实现与边界

React + Three.js + camera-controls + three-pathfinding + Howler，Cloudflare Worker/D1。多人采用 1.2 秒心跳和位置插值，面向小规模体验，尚未经过高并发或真机性能压测。私有在线预览不等于中国大陆服务器正式运营；国内规模化部署可迁移 Colyseus 权威房间服务。

所有模型由本项目程序化创建，声景由 scripts/make-soundscape.mjs 合成。无真实付费、真实开光或真实寺院录音；轻念采用设备语音。详细 GitHub 比选、出处与设计见 [研究与设计](docs/研究与设计.md)。
